Política de Privacidade

Última atualização: 29/08/2026

Esta política descreve como os dados são tratados.

Dados coletados

IDs do Discord e configurações necessárias para o funcionamento do bot.

Uso

Os dados são usados apenas para operar o bot.

Compartilhamento

Os dados não são vendidos a terceiros.

Exclusão

Você pode solicitar a exclusão dos seus dados entrando em contato com o desenvolvedor.
